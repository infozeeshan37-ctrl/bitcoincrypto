# BitcoinCrypto

A modern, responsive Cryptocurrency & Bitcoin live tracker designed for rapid deployment on Vercel.

## Features
- Real-time Bitcoin, Ethereum, and Solana price monitoring
- 24-hour market trend indicators
- Sleek dark mode UI with Tailwind CSS
- Fully static & zero-config ready for Vercel
